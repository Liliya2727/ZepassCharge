# ZEPASSCHARGE    
**Universal Bypass Charging Module for Rooted Devices**  

##  What is ZepassCharge?  
ZepassCharge is a **universal bypass charging module** designed for **rooted** Android devices. It allows users to **bypass battery charging** while gaming, reducing battery wear and improving thermal efficiency.  

##  Available Versions  
I have created **three different versions** of this module, each with a unique approach to bypass charging:  

| Version | Features |  
|---------|----------|  
| **T1** | Automatically charges when the battery is **below 30%**, but enables bypass when gaming above this level. Ideal for **battery-conscious users**. |  
| **T2** | Enables bypass at **any battery percentage** while gaming. Best for those who want **uninterrupted bypass charging**. |  
| **T3** | Bypass is controlled manually using **action.sh**. You can enable or disable it **whenever you want**. |  

##  Features  
- ✅ **Active automatically on gaming** (T1 & T2)  
- ✅ **Battery threshold at 30%** (T1)  
- ✅ **Activate manually** (T3)  
- ✅ **Reduce heating on gaming**

- **Works on KSU Magisk and Apatch**
